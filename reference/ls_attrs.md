# list built-in attributes name used in `cr_reframe()`

list built-in attributes name used in
[`cr_reframe()`](https://gigu003.github.io/canregtools/reference/cr_reframe.md)

## Usage

``` r
ls_attrs()
```

## Value

A character vector.

## Examples

``` r
ls_attrs()
#> [1] "registry"  "region"    "area_type" "province"  "city"     
```
