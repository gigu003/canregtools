# Construct a `canreg_report` object

Construct a `canreg_report` object

## Usage

``` r
new_canreg_report(meta, source = NULL, pop, quality, inci, mort)
```

## Arguments

- meta:

  Metadata list.

- source:

  Optional intermediate source objects.

- pop, quality, inci, mort:

  Report component lists.

## Value

An object of class `canreg_report`.
